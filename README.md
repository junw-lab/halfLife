Starbie

My starbie project is a tiny motion controlled pet. The parts involved include:
- Two push bottoms for interactivity
- A DHT11 environmental sensor to monitor temperature and humidity
- An OLED display module to show the sprite and let the user visually see its interaction
- An MPU6050 to give motion sensing capabilities to the starbie, allowing it to detect being moved around
- A AT42QT1010 to give the starbie a more discrete and calmer way of interaction compared to the switch
